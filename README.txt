Scraping the data
1. Open the terminal in the project folder
2. Run the command "pip install -r requirements.txt" to install the required libraries
3. Run the url_scrape.py file
4. Run the url_to_oracle.py file
5. Run the gig_scrape_to_oracle.py file
6. Run the data_cleaning.py

Data Mining
1. Upload the .ipynb files to Google Colab
2. Load the "gigs_cleaned.csv" file to the Topic_Modelling_Implementation_on_Descriptions Google Colab instance
3. Load the "reviews_cleaned.csv" file to the Topic_Modelling_Implementation_on_Reviews Google Colab instance
4. Load the "reviews_cleaned.csv" file to the Sentiment_Analysis Colab instance
5. Run the first code snippet first for both colab notebooks
6. Restart their sessions
7. You can now run all the code snippets.
